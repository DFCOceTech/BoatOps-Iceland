# S02-01: FastAPI Skeleton — App, Config, Cache, Router Stubs, Health Endpoint

> Status: Done | Epic: 02 | Last updated: 2026-05-02

## Description

Stand up the `src/boatops/` package with a working FastAPI app, pydantic-settings config
loaded from `.env`, TTL cache module, per-capability router stubs returning `501 Not Implemented`,
and a `/health` endpoint. No data fetching yet — just the scaffolding every subsequent story
will build on.

## OpenSpec References

- Architecture: `_bmad/architecture.md` — Phase 2 layout

## Acceptance Criteria

- [x] `src/boatops/main.py` starts with `uvicorn boatops.main:app --reload`
- [x] `GET /health` returns `{"status": "ok", "version": "0.1.0"}`
- [x] `GET /api/weather/forecast`, `/api/waves/overlay`, `/api/solar/times`, `/api/satellite/overpasses`, `/api/map/bathymetry` all return HTTP 501
- [x] `src/boatops/config.py` loads `CMEMS_USERNAME`, `CDSE_EMAIL`, `ANTHROPIC_API_KEY` from `.env` without error when vars present
- [x] `src/boatops/cache.py` exports a `make_cache(ttl_seconds)` factory backed by `cachetools.TTLCache`
- [x] `pytest tests/test_health.py` passes (no credentials required)

## Tasks

1. Create `src/boatops/` package with `__init__.py`
2. Write `config.py` using `pydantic-settings`
3. Write `cache.py` with `make_cache()` factory
4. Write stub router files (one per capability)
5. Write `main.py` — FastAPI app, CORS, router includes
6. Write `tests/test_health.py`
7. Verify `uvicorn` starts and `/health` returns 200

## Implementation Notes

- **Key files**: `src/boatops/main.py`, `src/boatops/config.py`, `src/boatops/cache.py`,
  `src/boatops/routers/`, `tests/test_health.py`
- CORS origin `*` for Phase 2 (localhost dev); lock down in Phase 3 deployment
- `cachetools.TTLCache` is not thread-safe by itself; wrap with `cachetools.cached` +
  `threading.RLock` in each service that uses it
