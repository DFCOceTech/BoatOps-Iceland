# S03-04: Weather + Waves Panels

> Status: Backlog | Epic: 03 | Last updated: 2026-05-03

## Description

Sidebar panels for weather forecast and wave conditions. Includes a 7-day wind/cloud
chart (Recharts), current conditions summary card, wave height overlay toggle, and
animated quiver overlay for currents.

## PRD References
FR-06 (wind), FR-07 (temperature), FR-08 (precipitation), FR-09 (cloud cover),
FR-12 (wave height), FR-13 (wave direction)

## Acceptance Criteria

- [ ] Weather panel: fetches `/api/weather/forecast?lat=54.18&lon=12.08`; displays wind speed (kt) + cloud cover (%) as 7-day Recharts time series; updates on AOI center change
- [ ] Current conditions card: wind speed + direction, temperature, cloud cover, precipitation
- [ ] Wind direction shown as compass arrow SVG
- [ ] Wave panel: fetches `/api/waves/forecast`; displays current Hs (m) + VMDR (°); Go/No-Go colour coding (green ≤0.4 m, amber ≤0.8 m, red >0.8 m)
- [ ] Wave height overlay toggleable from panel (fetches `/api/waves/overlay`)
- [ ] All charts show last-updated timestamp (NFR-05)
- [ ] Failed fetch: panel shows error state; map layers unaffected (NFR-06)

## Implementation Notes

- Weather advisories (`/api/weather/advisories`): show count badge; geometry=null so no map polygon (deferred to Phase 4 if DWD WFS is integrated)
- Recharts `ResponsiveContainer` + `ComposedChart` for wind speed + gusts fill
- 15 kt and 25 kt horizontal reference lines on wind chart (Go/No-Go thresholds)
