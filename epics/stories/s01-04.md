# S01-04: Satellite Overpass Notebook (CDSE, USGS/CMR, CelesTrak)

> Status: Done | Epic: 01 | Last updated: 2026-05-02

## Description

Create `notebooks/04_satellite_overpasses.ipynb` that queries CDSE OData for Sentinel-2/3 overpasses, NASA CMR for Landsat 8/9 overpasses, and CelesTrak TLEs + orbital propagation for VIIRS overpasses over a test Baltic AOI and 10-day planning window.

- Design: `openspec/capabilities/satellite/design.md`

- Scenarios: SCENARIO-SAT-S2-001, SCENARIO-SAT-VIIRS-001, SCENARIO-SAT-FAIL-001

## Acceptance Criteria

- [ ] (SCENARIO-SAT-S2-001) CDSE OData returns ≥1 Sentinel-2 acquisition for bbox `[9.5, 53.5, 15.0, 56.0]` over a 10-day window; includes platform, start/end time, footprint geometry
- [ ] (SCENARIO-SAT-VIIRS-001) CelesTrak TLE fetch + orbital propagation returns ≥1 VIIRS overpass with AOS, LOS, and ground track polyline for a 48-hour window
- [ ] Landsat 8/9 overpasses retrieved from NASA CMR API (or USGS M2M if key available)
- [ ] CDSE credentials loaded from `.env` — not hardcoded
- [ ] Notebook runs top-to-bottom in `boatops` env; output cleared before commit

## Tasks

1. Create `notebooks/04_satellite_overpasses.ipynb`
2. Load CDSE credentials from `.env`; implement OAuth2 token fetch (adapt from Sent2_GreenMac)
3. Build CDSE OData filter for Sentinel-2 A/B acquisitions by bbox and date range; paginate results
4. Repeat for Sentinel-3 A/B
5. Query NASA CMR API for Landsat 8/9 granules over AOI and date range (keyless)
6. Fetch CelesTrak TLE data for Suomi-NPP and NOAA-20
7. Implement orbital propagation using `skyfield` or `sgp4`; compute AOS/LOS and ground track
8. Filter ground tracks intersecting AOI bbox using `shapely`
9. Annotate each overpass with cloud cover (from Open-Meteo data) and solar elevation (from suncalc) at pass time
10. Tabulate and visualize all overpasses in a timeline plot
11. Document findings in `ops/data-sources.md`: CDSE OData filter syntax, NASA CMR endpoint, CelesTrak catalog URL

## Implementation Notes

- **Key files**: `notebooks/04_satellite_overpasses.ipynb`
- **Deviations**:
  - CelesTrak deprecated `satcat/tle.php` in 2020. New GP endpoint: `https://celestrak.org/NORAD/elements/gp.php?CATNR=<ID>&FORMAT=tle`.
  - NASA CMR returns 0 results for recent dates (processing lag). **TLE-based prediction via skyfield is used for all 6 platforms** (Sentinel-2A/B added to VIIRS+Landsat).
  - Skyfield `Time` objects are scalar — cannot use `if peak_t:` (raises TypeError). Must use `if peak_t is not None:`.
  - Sentinel-2A/B NORAD IDs: 40697 / 42063.
