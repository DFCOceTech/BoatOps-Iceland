# S03-02: Base Map — OSM, OpenSeaMap, Layer Toggle Panel

> Status: Backlog | Epic: 03 | Last updated: 2026-05-03

## Description

Fully functional base map with OSM + OpenSeaMap tile layers, a layer toggle panel
(checkbox list in the sidebar), coordinate readout on cursor hover, and scale bar.

## PRD References
FR-01 (layer toggles), FR-02 (OSM), FR-03 (OpenSeaMap)

## Acceptance Criteria

- [ ] OSM raster tiles load and render correctly at all zoom levels 4–16
- [ ] OpenSeaMap seamark overlay toggleable independently of OSM
- [ ] Layer panel in sidebar: checkbox per layer, label, visibility toggle
- [ ] Cursor lat/lon displayed in footer bar (4 decimal places)
- [ ] MapLibre scale bar visible bottom-left
- [ ] GEBCO WMS and EMODnet WMS layers added to toggle panel (FR-17, FR-18); render on toggle

## Implementation Notes

- GEBCO and EMODnet are WMS sources — add as `raster` source in MapLibre with tiles array
- OpenSeaMap: `https://tiles.openseamap.org/seamark/{z}/{x}/{y}.png`
