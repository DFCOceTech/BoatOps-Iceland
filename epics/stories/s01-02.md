# S01-02: Wave Data Notebook (CMEMS Baltic Wave Forecast)

> Status: Done | Epic: 01 | Last updated: 2026-05-02

## Description

Create `notebooks/02_waves.ipynb` that authenticates to CMEMS and retrieves significant wave height (VHM0) and mean wave direction (VMDR) from the Baltic Sea Wave Analysis and Forecast product for a test AOI. Determine whether the `copernicusmarine` Python client or MOTU client is more practical for the web backend.

- [ ] (SCENARIO-WAVE-DIR-001) Wave direction co-located with Hs; values in [0, 360)
- [ ] (SCENARIO-WAVE-SNAPSHOT-001) Single time-slice extraction works
- [ ] (REQ-WAVE-003) Model run time and last-updated time documented in output

## Tasks

1. Create `notebooks/02_waves.ipynb`
2. Load CMEMS credentials from `.env` using `python-dotenv`
3. Try `copernicusmarine.subset()` for product `BALTICSEA_ANALYSISFORECAST_WAV_003_010`, variables VHM0 and VMDR
4. If copernicusmarine unavailable, fall back to MOTU client
5. Subset by test bbox and 48-hour time window; load as xarray Dataset
6. Extract single time snapshot; confirm data shapes
7. Visualize: pcolormesh(Hs), quiver(wave_dir) using matplotlib/cartopy
8. Check model run time metadata; document in `ops/data-sources.md`
9. Document CMEMS product ID, dataset ID, variable names, spatial/temporal resolution

## Implementation Notes

- **Key files**: `notebooks/02_waves.ipynb`
- **Deviations**:
  - CMEMS credentials are **separate from CDSE** — use account in `COPERNICUSMARINE_SERVICE_USERNAME` (cached in `~/.copernicusmarine/`). `.env` key: `COPERNICUSMARINE_SERVICE_USERNAME/PASSWORD`.
  - Warnemünde (54.18°N, 12.08°E) maps to a **land-masked grid cell** (100% NaN). Phase 2 service must search for nearest non-NaN (wet) cell.
  - `copernicusmarine.open_dataset()` returns tz-naive `numpy.datetime64` time coordinates — use `pd.Timestamp(now_utc).tz_localize(None)` for comparisons.
