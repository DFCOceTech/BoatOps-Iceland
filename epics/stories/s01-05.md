# S01-05: Sentinel-2 Imagery Notebook (CDSE STAC + WMS)

> Status: Done | Epic: 01 | Last updated: 2026-05-02

## Description

Create `notebooks/05_sentinel2_imagery.ipynb` that searches the CDSE STAC API for the most recent cloud-free Sentinel-2 Level-2A scene over a test Baltic AOI, retrieves scene metadata, and streams a tile via the CDSE OGC WMS/WMTS service. Adapts authentication and query patterns from the `Sent2_GreenMac` CDSE_OData_Workflow_v1.ipynb.

## Acceptance Criteria

- [ ] (SCENARIO-SAT-IMG-001) CDSE STAC search returns the most recent Sentinel-2 scene with cloud cover ≤ 20% for the test AOI; acquisition date, cloud cover %, and scene ID returned
- [ ] (SCENARIO-SAT-IMG-002) When no scene meets the threshold, response is an empty result (not an error)
- [ ] CDSE WMS tile URL constructed correctly for true color (B4/B3/B2) and false color (B8/B4/B3)
- [ ] Scene displays as a georeferenced overlay in ipyleaflet or folium
- [ ] CDSE credentials loaded from `.env`; output cells cleared before commit

## Tasks

1. Create `notebooks/05_sentinel2_imagery.ipynb`
2. Reuse CDSE OAuth2 token logic from s01-04 (or import from a shared cell)
3. Query CDSE STAC API: search by AOI bbox, collection `SENTINEL-2`, `eo:cloud_cover` ≤ 20%, sort by `datetime` descending, take first result
4. Extract scene ID, acquisition date, cloud cover, tile grid reference from STAC item
5. Construct CDSE OGC WMS GetMap URL for true color (B4/B3/B2) and false color (B8/B4/B3)
6. Display tile as map overlay in ipyleaflet or folium for visual confirmation
7. Test the no-results case (set threshold very low, e.g., 0%)
8. Review patterns from `Sent2_GreenMac/CDSE_OData_Workflow_v1.ipynb` for any reusable auth or query patterns not already captured
9. Document CDSE STAC endpoint, collection IDs, and WMS URL template in `ops/data-sources.md`

## Implementation Notes

- **Key files**: `notebooks/05_sentinel2_imagery.ipynb`
- **Related prior work**: `~/Documents/myRepos/Sent2_GreenMac/CDSE_OData_Workflow_v1.ipynb`
- **Deviations**:
  - CDSE STAC (`stac.dataspace.copernicus.eu/v1`) does **not** contain Sentinel-2 — use OData for discovery.
  - OData does **not** accept `$expand=Attributes,Assets` combined (400 error) — two separate requests required.
  - Quicklook asset is **JPEG**, not PNG — use `PIL.Image.open()`, not `matplotlib.image.imread()`.
  - **Sentinel Hub Process API** (`sh.dataspace.copernicus.eu/api/v1/process`) works with the standard CDSE OAuth2 Bearer token — no separate instance ID needed.
  - Partial tile check **added** (adapted from Sent2_GreenMac): spherical Shoelace formula on GeoFootprint; rejects scenes where `coverage < 50%`. Fetches pool of 20 candidates and iterates.
