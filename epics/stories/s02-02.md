## Acceptance Criteria

- [ ] `GET /api/weather/forecast?lat=54.18&lon=12.08` returns JSON with `wind_speed_ms`,
  `wind_dir_deg`, `temperature_c`, `precipitation_mm`, `cloud_cover_pct` as 168-item hourly arrays
- [ ] `GET /api/weather/advisories?country=DE` returns GeoJSON FeatureCollection (may be empty)
- [ ] Both endpoints include `last_updated` ISO timestamp in response
- [ ] Open-Meteo responses cached TTL=15 min; MeteoAlarm TTL=5 min
- [ ] If upstream returns non-200, endpoint returns HTTP 502 with `{"detail": "upstream error: ..."}`
- [ ] `pytest tests/test_weather.py` passes with `httpx` mock

## Tasks

1. Extract Open-Meteo query into `services/openmeteo.py`; add met→knots conversion helper
2. Extract MeteoAlarm Atom parse into `services/meteoalarm.py`; return as GeoJSON stub
   (geometry=null, properties contain area text — polygon deferred, see notebook deviation note)
3. Wire into `routers/weather.py` with `APIRouter(prefix="/api/weather")`
4. Add TTL cache decorators
5. Write tests with `respx` or `unittest.mock` for both services

## Implementation Notes

- Open-Meteo: no auth required; base URL `https://api.open-meteo.com/v1/forecast`
- MeteoAlarm: Atom XML, no auth; area geometry is plain text (no polygon in feed)
- Wind direction can be exactly 360° — do not assert `< 360`
- Gotcha: `cloudcover` is the Open-Meteo variable name (no underscore)
