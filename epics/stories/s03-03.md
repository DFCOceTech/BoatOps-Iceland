# S03-03: Oceanographic Overlays — `/api/map/*` PNG Layers

> Status: Done | Epic: 03 | Last updated: 2026-05-03

## Description

Fetch all six CMEMS overlay PNGs from the FastAPI backend and render as georeferenced
image layers in MapLibre GL JS. Each layer has a colorscale legend, timestamp badge,
and error state (grey placeholder + error icon if fetch fails — NFR-06).

## PRD References
FR-17 (GEBCO), FR-18 (EMODnet), FR-19 (SST), FR-20 (Salinity), FR-21 (Currents), FR-22 (Chl), FR-23 (O₂)

## Acceptance Criteria

- [ ] Each overlay fetched from `/api/map/{bathymetry,sst,salinity,currents,chlorophyll,oxygen}`
- [ ] PNG rendered as MapLibre `ImageSource` + `RasterLayer` within the AOI bbox
- [ ] Colorscale legend (vmin–vmax, cmap name) rendered from `X-Colorscale` header
- [ ] Timestamp badge rendered from `X-Timestamp` header (NFR-05)
- [ ] Failed fetch shows grey overlay with error message; other layers unaffected (NFR-06)
- [ ] Layer opacity slider in sidebar (0–100%)

## Implementation Notes

- Fetch PNG as `blob()`, create `URL.createObjectURL(blob)` for MapLibre `ImageSource`
- Parse `X-Colorscale` header JSON to drive the legend component
- `X-Bbox` header: `west,south,east,north` — use as `ImageSource.coordinates`
- Cleanup: revoke object URL on layer removal to prevent memory leak
