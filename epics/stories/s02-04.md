  `sunrise`, `sunset`, `civil_dawn`, `civil_dusk`, `nautical_dawn`, `nautical_dusk`,

- [ ] `GET /api/solar/elevation?lat=54.18&lon=12.08` returns JSON with current

- [ ] No caching needed (fully deterministic); response time < 10 ms
- [ ] `pytest tests/test_solar.py` passes (no network calls)
