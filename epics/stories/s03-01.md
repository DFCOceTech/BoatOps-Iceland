# S03-01: Project Scaffold — Vite + React + TypeScript + MapLibre GL JS

> Status: Done | Epic: 03 | Last updated: 2026-05-03

## Description

Bootstrap the `frontend/` directory with a Vite + React 18 + TypeScript project,
install MapLibre GL JS, create the two-panel layout shell (full-screen map left,
collapsible sidebar right), and wire up a typed API client module that proxies
`/api/*` to the FastAPI backend during development.

## Acceptance Criteria

- [x] `npm run dev` in `frontend/` starts without errors; browser shows map at localhost:5173
- [x] MapLibre GL JS map renders centered on Baltic AOI (54.18°N, 12.08°E), zoom 8
- [x] Layout: full-screen map + right sidebar (collapsible); responsive to window resize
- [x] `src/api/client.ts` exports typed fetch wrappers for every backend endpoint
- [x] `npm run build` succeeds (no TypeScript errors)
- [x] Vite dev proxy forwards `/api/*` to `http://localhost:8000`

## Tasks

1. `npm create vite@latest frontend -- --template react-ts`
2. Install: `maplibre-gl`, `recharts`
3. Set up Vite proxy for `/api/*` → `http://localhost:8000`
4. Write `src/api/client.ts` with typed fetch functions for all 14 endpoints
5. Write `src/components/MapView.tsx` — MapLibre GL JS map centred on Baltic
6. Write `src/components/Sidebar.tsx` — collapsible right panel shell
7. Write `src/App.tsx` — two-panel layout
8. Verify `npm run build` passes TypeScript checks

## Implementation Notes

- **Key files**: `frontend/src/`, `frontend/vite.config.ts`, `frontend/src/api/client.ts`
- MapLibre GL JS requires `import 'maplibre-gl/dist/maplibre-gl.css'` in main entry
- Use OSM raster tile style for Phase 3 base map; vector style deferred
- Sidebar width: 380px; collapses to 0 on narrow viewports
