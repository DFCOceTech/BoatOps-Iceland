# S03-05: Solar + Satellite Panels

> Status: Backlog | Epic: 03 | Last updated: 2026-05-03

## Description

Sidebar panels for solar geometry and satellite overpasses. Solar panel shows today's
events table and a live elevation gauge. Satellite panel shows a 7-day overpass
timeline table and toggles the Sentinel-2 overlay on the map.

## PRD References
FR-11 (solar), FR-14 (overpasses), FR-15 (S2 overlay)

## Acceptance Criteria

- [ ] Solar panel: fetches `/api/solar/times`; table of sunrise/sunset/twilight times in local time (CET/CEST); null values shown as "—" (polar edge case)
- [ ] Solar elevation gauge: fetches `/api/solar/elevation` every 60 s; arc gauge showing current elevation; period label (day/civil twilight/night etc.)
- [ ] Satellite panel: fetches `/api/satellite/overpasses`; table grouped by platform; AOS/LOS times, max elevation, duration
- [ ] Optimal passes highlighted: solar elevation at midpass > 20° shown in green
- [ ] S2 overlay toggle: fetches `/api/satellite/s2-overlay`; renders as MapLibre `ImageSource`; shows acquisition date + cloud cover badge (NFR-05)
- [ ] S2 fetch can take 10–30 s — show loading spinner during fetch (NFR-06)

## Implementation Notes

- Solar times: browser `Intl.DateTimeFormat` with `Europe/Berlin` for local display
- Overpass table: sort by AOS ascending; columns: Platform | AOS | Duration | Max Elev
- S2 overlay bbox from `X-Bbox` header; `X-Acquisition-Time` for the date badge
