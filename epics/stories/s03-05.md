# S03-05: Solar + Satellite Panels

> Status: Done | Epic: 03 | Last updated: 2026-05-03

## Description

Sidebar panels for solar geometry and satellite overpasses. Solar panel shows today's
events table and a live elevation gauge. Satellite panel shows a 7-day overpass
timeline table and toggles the Sentinel-2 overlay on the map.

## PRD References
FR-11 (solar), FR-14 (overpasses), FR-15 (S2 overlay)

## Acceptance Criteria

- [x] Solar panel: fetches `/api/solar/times`; table of sunrise/sunset/twilight times in local time (CET/CEST); null values shown as "—" (polar edge case)
- [x] Solar elevation gauge: fetches `/api/solar/elevation` every 60 s; arc gauge showing current elevation; period label (day/civil twilight/night etc.)
- [x] Satellite panel: fetches `/api/satellite/overpasses`; table grouped by platform; AOS/LOS times, max elevation, duration
- [x] Optimal passes highlighted: **Deviation** — satellite max elevation ≥ 20° shown in green; today's daytime passes (AOS between sunrise and sunset) highlighted with row background. Full per-pass solar elevation requires a backend schema change (`Overpass` type has no `midpass_solar_elevation_deg` field); deferred to S03-06 or backend update.
- [x] S2 overlay toggle: fetches `/api/satellite/s2-overlay`; renders as MapLibre `ImageSource`; shows acquisition date + cloud cover badge (NFR-05)
- [x] S2 fetch can take 10–30 s — show loading spinner during fetch (NFR-06)

## Implementation Notes

- Solar times: browser `Intl.DateTimeFormat` with `Europe/Berlin` for local display
- Overpass table: grouped by platform (alphabetical) with platform-colored section headers; within each group sorted by AOS; columns: AOS (Berlin) | Duration | Max Sat Elev
- S2 overlay: manual MapLibre `ImageSource` + `RasterLayer` lifecycle (not via `useApiLayers` — satellite router emits `X-Scene-Id`/`X-Acquisition-Time`/`X-Cloud-Cover` instead of `X-Timestamp`/`X-Colorscale`)
- `getS2Overlay` accepts optional `AbortSignal` threaded all the way to `fetch()` — critical for cancelling the 10–30 s request on toggle-off or unmount
- `mapRef` pattern in `toggleS2` avoids stale map closure after async window

## Gate 4 (Raze) Fixes

Six findings resolved:
1. `AbortController.signal` was not threaded to `fetch()` in `fetchS2Png` — fixed in `client.ts`
2. `doAdd` closure captured stale closed-over `map` — fixed with `mapRef.current`
3. `map.once('load', doAdd)` could fire post-unmount — fixed with `mountedRef` guard inside `doAdd`
4. Overpass table not grouped by platform — fixed with `groupByPlatform()`
5. Astronomical dawn/dusk row missing from solar times table — added
6. "Optimal passes" legend incorrectly implied solar elevation — legend text clarified
