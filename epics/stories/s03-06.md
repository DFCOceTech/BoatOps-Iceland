# S03-06: Go/No-Go Dashboard

> Status: Backlog | Epic: 03 | Last updated: 2026-05-03

## Description

A summary dashboard panel at the top of the sidebar showing a per-capability
status indicator (green/amber/red) and an overall Go/No-Go recommendation.
All thresholds configurable via constants; no backend call required — derived
from data already fetched by other panels.

## PRD References
FR-01 (planning dashboard)

## Thresholds (defaults, all configurable)

| Capability | Green | Amber | Red |
|---|---|---|---|
| Wind | ≤ 15 kt | ≤ 25 kt | > 25 kt |
| Gusts | ≤ 20 kt | ≤ 30 kt | > 30 kt |
| Wave height (Hs) | ≤ 0.4 m | ≤ 0.8 m | > 0.8 m |
| Cloud cover | ≤ 20% | ≤ 50% | > 50% |
| Solar elevation | ≥ 20° | ≥ 10° | < 10° |

Overall: **Go** if all green; **Caution** if any amber and no red; **No-Go** if any red.

## Acceptance Criteria

- [ ] Dashboard card at top of sidebar with overall verdict (Go/Caution/No-Go)
- [ ] Per-capability rows: icon + label + status dot (green/amber/red) + current value
- [ ] Overall verdict derived from per-capability statuses; updates reactively as data loads
- [ ] "Last refreshed" timestamp shown; manual refresh button
- [ ] Capabilities with pending/failed data shown as "—" (grey dot); overall verdict held until all data loads
- [ ] Thresholds editable via a settings modal; persisted to `localStorage`
