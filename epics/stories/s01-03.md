# S01-03: Solar Geometry Notebook (suncalc)

> Status: Done | Epic: 01 | Last updated: 2026-05-02

## Description

Create `notebooks/03_solar.ipynb` that computes solar geometry for example Baltic locations and dates using the `suncalc` Python library. Validate outputs against USNO Solar API reference values. Generate a sub-hourly timeline of solar elevation across a planning window. Handle the polar summer edge case (no sunset).

## Implementation Notes

- **Key files**: `notebooks/03_solar.ipynb`
- **Deviations**:
  - `suncalc.get_times()` argument order is **(lng, lat)** not (lat, lon) — easy gotcha.
  - Returns **tz-naive `pd.NaT`** (not Python `None`) for events that don't occur (e.g. polar summer). Use `pd.isna(v)` to detect, then localize with `v.tz_localize("UTC")`.
  - Altitude and azimuth are returned in **radians**, not degrees. Azimuth convention: south=0; convert to north=0 via `(deg(az) + 180) % 360`.
  - SCENARIO-SOL-ACCURACY-001 placeholder values still need real USNO lookup at `aa.usno.navy.mil/data/RS_OneYear` for Warnemünde 2026-09-15.
