# S02-06: Map Layers Router — Oceanographic Overlay PNGs

> Status: Backlog | Epic: 02 | Last updated: 2026-05-02

## Description

Expose all CMEMS raster overlay layers from `notebooks/06_map_layers.ipynb` as binary PNG
endpoints, plus the static GEBCO bathymetry. Reuses `services/cmems.py` from S02-03.

## OpenSpec References

- Spec: `openspec/capabilities/map/spec.md`
- Requirements: REQ-MAP-001–016
- Scenarios: SCENARIO-MAP-GEBCO-001, SCENARIO-MAP-SST-OVERLAY-001,
  SCENARIO-MAP-SAL-OVERLAY-001, SCENARIO-MAP-CUR-OVERLAY-001,
  SCENARIO-MAP-CHL-OVERLAY-001, SCENARIO-MAP-O2B-OVERLAY-001

## Acceptance Criteria

- [ ] `GET /api/map/bathymetry?west=9.5&south=53.5&east=15.0&north=56.0` → `image/png`,
  cmocean.deep, land=transparent
- [ ] `GET /api/map/sst`, `/api/map/salinity`, `/api/map/chlorophyll`, `/api/map/oxygen`
  each return `image/png` with correct cmocean colormap and `X-Bbox`/`X-Timestamp` headers
- [ ] `GET /api/map/currents` returns `image/png` (quiver overlay, cmocean.speed)
- [ ] All layer endpoints include `X-Colorscale: {"vmin": ..., "vmax": ..., "cmap": "..."}` header
  so the frontend can render a legend without hardcoding
- [ ] Bathymetry cached TTL=24 hours (static dataset); oceanographic layers cached TTL=1 hour
- [ ] `pytest tests/test_map_layers.py` passes with mocked CMEMS

5. Write tests
